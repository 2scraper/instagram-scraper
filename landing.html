Open-source social profile data

Public Instagram profiles and posts, no login.

Open-source scraper for public Instagram profiles, posts and Reels. Three engines, one documented output schema — followers, bio, links, likes, comments, captions, hashtags, every carousel image. Reads what Instagram shows any logged-out visitor: no account, nothing to ban.

View on GitHub Read the docs
Before you scrape: Instagram's robots.txt disallows crawlers and Meta's terms forbid automated collection without permission. This tool reads only what any logged-out visitor is shown, never logs in and never collects comments — but whether your use is allowed depends on where you are and what you do with the data. Check first, and never use it to track individuals.
What to expect: every row comes from the data Instagram embeds in the page itself — not from the rounded preview text. Live-verified on 2026-10-04 from an ordinary residential IP with no key and no proxy: a profile and its 12 latest posts, 13 of 13 pages; a 29-page mixed run with two dead inputs reported as not found. Instagram limits logged-out reading per client: a throttled run says so (blocked, rate_limited) instead of returning an empty profile. A logged-out profile shows its 12 most recent posts, so that is the limit here too. Full details in the README.

Risk management

Infrastructure, when you want it

PROXIES

The one that matters here: Instagram limits logged-out reading per client. 2captcha.com/proxy residential exits in .env or --proxy-file — rotated per URL, with per-exit failure tracking and masked logs.

SCRAPER API

No browser at all: --scraper-api fetches each profile and post page from 2Captcha's side, one HTTP call each.

SCRAPING BROWSER API

A remote browser session over CDP with its own proxy, fingerprint, and captcha auto-solve bundled — one --cdp-endpoint flag.

FINGERPRINTS

Optional: pin a specific OS/browser/country fingerprint via the 2Captcha Fingerprint API for a locally-launched browser.

Get started

# clone and install — no key needed to start
git clone https://github.com/2scraper/instagram-scraper.git
cd instagram-scraper && pip install -r requirements-playwright.txt && playwright install chromium

# a profile and its 12 most recent posts
python3 playwright_scraper.py --url natgeo --posts 12 --format json --out results.json

# or one post or Reel, or a batch of usernames from a file
python3 playwright_scraper.py --url "https://www.instagram.com/p/DeAZ0uAgNuA/"
python3 playwright_scraper.py --urls-file accounts.txt --posts 3

Built for brand, market and media research on public accounts — anything behind a login (followers lists, stories, the full timeline, comments) is out of scope.
